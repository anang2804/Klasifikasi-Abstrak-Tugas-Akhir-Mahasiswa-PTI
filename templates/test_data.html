Tentang Halaman Ini
Apa itu Riwayat Klasifikasi?

Halaman ini menampilkan riwayat hasil klasifikasi yang dilakukan oleh user melalui Menu Klasifikasi. Data ini berasal dari:

  • Input Manual - Teks abstrak yang di-copy-paste ke form input
  • Upload File - File TXT/PDF/DOCX yang di-upload
Fungsi Halaman Ini:
Tracking Klasifikasi

Menyimpan history semua klasifikasi yang pernah dilakukan user, lengkap dengan prediksi, confidence, dan waktu klasifikasi.

Simpan ke Dataset

Data yang akurat bisa disimpan ke dataset training untuk meningkatkan performa model di training berikutnya.

Tips: Gunakan tombol untuk menyimpan data yang prediksinya sudah benar ke database training, sehingga bisa digunakan untuk melatih model di masa depan.
